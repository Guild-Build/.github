### One company. An open guild.

**GuildBuild** is a Canadian data and AI engineering company. We build trusted data foundations, clear analytics, and practical AI workflows, including Microsoft Fabric and Power BI solutions.

**BuildGuild**, by GuildBuild Inc., is the open guild for agent engineering. Learn, assemble an agent build, run a trial, and share evidence others can reproduce. A build brings together the skills, subagents, hooks, tools, and settings a coding agent runs with. Tiers come from published trial evidence.

### Find your first step

- **Learn:** [What is an agent build?](https://buildguild.gg/guides/what-is-an-agent-build/)
- **Build:** browse [agent builds](https://buildguild.gg/builds/) or assemble one in the [planner](https://buildguild.gg/planner/).
- **Prove:** run a [trial](https://buildguild.gg/trials/) and contribute reproducible evidence through Build.
- **Connect:** ask a question or propose a guide in [Guild Discussions](https://github.com/Guild-Build/Guild/discussions).

Read the [code of conduct](https://github.com/Guild-Build/Guild/blob/main/code-of-conduct.md) and [guild oaths](https://github.com/Guild-Build/Guild/blob/main/oaths.md) before contributing. Share only material you have permission to publish. Keep credentials, personal data, and client information out of issues, discussions, pull requests, and evidence.
