# GuildBuild on GitHub

This repository maintains the public [GuildBuild organization profile](https://github.com/Guild-Build).

- `profile/README.md` is the organization overview.
- `profile/assets/` contains the GuildBuild logos used by the overview, with light and dark variants.

Keep profile copy grounded in the public GuildBuild and BuildGuild websites and public repositories. Publish no client information, private repository material, credentials, or personal data. Follow the contribution and license guidance in each linked project.

The GuildBuild name and logos identify GuildBuild Inc. Their inclusion here does not grant a trademark license.
